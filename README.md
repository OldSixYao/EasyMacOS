# EasyMacOS

原生 macOS 工具集，包含剪贴板历史、截图标注、桌面钉图、访达右键菜单和鼠标滚动增强。适用于 Apple Silicon Mac，系统要求 macOS 15 或更新版本。

## 剪贴板历史

- 用 **⌘⇧V** 或菜单栏图标打开历史，找回复制过的文字和图片。
- 支持搜索、收藏，以及按内容类型和来源应用筛选。
- 选择记录即可粘贴，也可以仅复制内容。
- 普通历史默认保留 30 天、最多 500 条；收藏内容保留至手动删除。
- 可暂停记录、排除指定应用，并设置保留时间和数量。
- 切换应用时丢弃尚未检测、来源无法确认的复制内容，减少应用排除的来源误判。

## 截图与标注

- 用 **⌃⌥A** 或菜单栏中的“截图”框选屏幕区域，支持调整位置和大小。
- 光标旁显示像素放大预览、坐标与色值；框选期间按 **⌘C** 可复制色值。
- 紧凑横向工具栏支持矩形、椭圆、箭头、画笔、文字和马赛克，颜色与粗细按需展开，并支持撤销、重做。
- 截图可直接复制、保存为 PNG，或钉在桌面；按 Esc 或鼠标右键取消截图，屏幕中央不显示操作提示。
- 钉图仅显示图片，无顶部系统按钮；支持多图、拖动和等比缩放，双击可关闭当前钉图，右键可复制、保存或恢复原始比例。
- 仅复制截图时按现有记录开关加入历史；保存和钉图不会额外写入历史。钉图在退出应用后关闭。

## 访达右键菜单

- 在访达的文件、文件夹或空白处右键，直接从一级菜单使用常用操作。
- 「新建文件」子菜单默认提供 `.txt`、`.json`、`.xml`、`.md`、`.csv`、`.html`、`.css`、`.js`，可在设置中添加或删除后缀，支持复合后缀。
- 选择类型后立即创建空文件，重名自动编号；已有辅助功能权限且确认选区后自动进入访达原地重命名，否则提示选中文件后按回车。取消重命名会保留文件。
- 访达设置直接显示自动重命名状态，可用“开启自动重命名…”授权；未授权时的新建提示也提供同一入口。菜单图标跟随系统深浅外观。
- 支持复制完整路径和文件名，多选时批量复制。
- 支持剪切文件与文件夹，在目标目录右键“粘贴（移动）”或按 ⌥⌘V 完成原生移动；剪切时源文件保持原位，普通粘贴仍执行复制。
- 移动沿用访达的同名冲突处理、进度和撤销，需要已有辅助功能权限。复制其他内容后，先前的剪切记录自动失效。
- 可在所选文件夹或文件所在目录打开系统终端。
- 设置窗口按通用、截图、剪贴板、右键菜单、鼠标和权限分为六个标签页。
- 与剪贴板、截图共用同一个 EasyMacOS 应用；首次使用需在系统设置中启用访达扩展。

## 鼠标滚动增强

- 在设置的“鼠标”页开启，支持普通鼠标滚轮平滑滚动、独立反向、半倍至三倍速度，以及平滑时长调节。
- 首次默认关闭，设置自动保存在本机；平滑关闭后，速度和反向仍可使用。反向相对于系统当前方向翻转，不修改系统设置。
- 默认保留设备原生连续滚动；远程桌面将鼠标滚轮转换为连续事件、导致增强无效时，可开启“远程滚轮兼容”，让这类滚动也使用平滑、方向和速度设置。
- 触控板手势与惯性滚动保持系统行为，命令键或控制键组合滚动也交由原应用处理。
- 可选择应用或填写应用标识加入排除名单，排除后沿用原生方向、速度和滚动，与剪贴板排除名单分别管理。
- 钉图滚轮缩放和本应用设置页保持原有操作；锁屏和休眠时暂停，恢复后按已保存的开关继续运行。
- 需要辅助功能权限，鼠标页显示运行状态，并提供授权或启动失败后的重试入口。

## 本机与隐私

内容仅保存在本机，无云同步和使用追踪。剪贴板记录、自动粘贴和截图分别使用相应的系统权限。访达自动重命名复用辅助功能权限，新建文件本身无需此权限。截图仅在主动触发时捕获屏幕。EasyMacOS 仅在用户选择菜单操作时复制路径、创建项目或打开目录，不扫描文件内容。

剪贴板与截图应用的菜单栏菜单、图标提示和设置页均显示当前应用版本。截图与历史快捷键可独立修改，并支持开机启动、中英文界面及系统深浅色外观。访达菜单配置与主应用共用界面，同样适配系统深浅色外观。
