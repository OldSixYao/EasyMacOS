# EasyMacOS

原生 macOS 工具集，包含剪贴板历史、截图标注、自动滚动长截屏、桌面钉图、屏幕录制、访达右键菜单和鼠标滚动增强。适用于 Apple Silicon Mac，系统要求 macOS 15 或更新版本。

截图、录屏、剪贴板、右键菜单和鼠标增强可在各自设置页独立开启或关闭，选择自动保存在本机。关闭后保留配置，剪贴板历史与收藏、已有桌面钉图也会保留。

## 剪贴板历史

- 用 **⌘⇧V** 或菜单栏图标打开历史，找回复制过的文字和图片。
- 支持搜索、收藏，以及按内容类型和来源应用筛选。
- 选择记录即可粘贴，也可以仅复制内容。
- 普通历史默认保留 30 天、最多 500 条；收藏内容保留至手动删除。
- 可暂停记录、排除指定应用，并设置保留时间和数量。
- 切换应用时丢弃尚未检测、来源无法确认的复制内容，减少应用排除的来源误判。

## 截图与标注

- 用 **⌃⌥A** 或菜单栏中的“截图”框选屏幕区域，支持调整位置和大小。
- 光标旁显示像素放大预览、坐标与色值；框选期间按 **⌘C** 可复制色值。
- 紧凑横向工具栏支持矩形、椭圆、箭头、画笔、文字和马赛克，颜色与粗细按需展开，并支持撤销、重做。
- 截图可直接复制、保存为 PNG，或钉在桌面；按 Esc 或鼠标右键取消截图，屏幕中央不显示操作提示。
- 钉图仅显示图片，无顶部系统按钮；支持多图、拖动和等比缩放，双击可关闭当前钉图，右键可复制、保存或恢复原始比例。
- 仅复制截图时按现有记录开关加入历史；保存和钉图不会额外写入历史。钉图在退出应用后关闭。

## 长截屏

- 在菜单栏选择“长截屏…”，或普通截图框选后点击“开始长截屏”，自动从当前位置向下滚动并拼成长图；已有标注时先重新框选。
- 支持单块显示器、单个窗口中的纵向滚动区域，保留原始清晰度，需要屏幕录制与辅助功能权限。完成授权后重新开始本次操作。
- 透明边框和悬浮条显示截取尺寸，可随时“停止并编辑”或取消；滚动到底后自动打开长图编辑窗口，边框、控制条和鼠标指针不进入成片。
- 自动滚动固定作用于框选区域，鼠标可自由移动，移出选区不改变滚动目标。
- 长图在独立预览区居中显示，可滚动查看，顶部工具栏固定，支持适应宽度、原始比例，以及矩形、椭圆、箭头、画笔、文字、马赛克和撤销重做。
- 可复制、保存图片或钉在桌面；取消保存或输出失败后仍可继续编辑，仅复制动作按原有隐私与容量规则尝试加入历史。
- 无法可靠拼接、目标窗口变化或达到五万像素高度、一亿总像素、三分钟任一上限时，停止并保留可靠内容。结束后页面留在实际滚动位置，采集期间暂停本应用的鼠标增强。

## 屏幕录制

- 支持全屏与区域录制：全屏录制先选择一块显示器，再点击开始或按回车确认；区域录制可拖动内部移动、拖动边角缩放，开始与取消按钮显示在选区旁。
- 确认选区后三秒开始，选择和倒计时期间可按退出键取消。
- 紧凑单行悬浮计时条提供暂停、继续和停止，可拖动位置；区域录制优先将控制条放在选区外。
- 全屏和区域录制持续显示细高亮边框，暂停时改为橙色，不拦截鼠标操作。暂停时间不会进入成片，边框、控制条和本应用窗口不会录入视频。
- 系统声音与麦克风可分别开启，默认只录画面；录屏包含鼠标指针。
- 画质可选标准与轻量：标准保留更高分辨率和帧率，轻量适合录制桌面操作、减少资源占用。
- 视频自动保存为 `.mp4`，默认位于“影片”下的 `EasyMacOS` 文件夹，可在录屏设置中更改目录。
- 全屏、区域、暂停／继续、停止的默认快捷键分别为 **⌃⌥R**、**⌃⌥⇧R**、**⌃⌥P**、**⌃⌥S**，均可自定义。
- 保存完成后可打开视频或在访达中定位，操作后完成窗口自动关闭；保存失败时保留片段，可重试保存，重启后也可恢复。

## 访达右键菜单

- 在访达的文件、文件夹或空白处右键，直接从一级菜单使用常用操作。
- 「新建文件」子菜单默认提供 `.txt`、`.json`、`.xml`、`.md`、`.csv`、`.html`、`.css`、`.js`，以及空白文字文档 `.docx`、电子表格 `.xlsx`、演示文稿 `.pptx` 和便携文档 `.pdf`；办公文档无需安装办公软件即可创建，可在设置中添加或删除后缀，支持复合后缀。
- 每种文件类型在菜单和设置中显示对应图标，可选择本地图片或恢复默认图标；图片导入后独立保存，生成文件的图标仍由系统管理。
- 选择类型后立即创建空文件，重名自动编号；已有辅助功能权限且确认选区后自动进入访达原地重命名，否则提示选中文件后按回车。取消重命名会保留文件。
- 权限页统一管理辅助功能与访达扩展授权；右键菜单页独立配置常用操作和文件类型。菜单图标跟随系统深浅外观。
- 支持复制完整路径和文件名，多选时批量复制。
- 支持剪切文件与文件夹，在目标目录右键“粘贴（移动）”或按 ⌥⌘V 完成原生移动；剪切时源文件保持原位，普通粘贴仍执行复制。
- 移动沿用访达的同名冲突处理、进度和撤销，需要已有辅助功能权限。复制其他内容后，先前的剪切记录自动失效。
- 可在所选文件夹或文件所在目录打开系统终端。
- 通过“显示／隐藏隐藏文件”切换访达中隐藏项目的可见性，无需重启访达；需要辅助功能权限。
- 设置窗口按通用、截图、剪贴板、右键菜单、鼠标、权限和录屏分为七个标签页。
- 与剪贴板、截图共用同一个 EasyMacOS 应用；首次使用需在系统设置中启用访达扩展。

## 鼠标滚动增强

- 在设置的“鼠标”页开启，支持普通鼠标滚轮平滑滚动、独立反向、半倍至三倍速度，以及平滑时长调节。
- 首次默认关闭，设置自动保存在本机；平滑关闭后，速度和反向仍可使用。反向相对于系统当前方向翻转，不修改系统设置。
- 默认保留设备原生连续滚动；远程桌面将鼠标滚轮转换为连续事件、导致增强无效时，可开启“远程滚轮兼容”，让这类滚动也使用平滑、方向和速度设置。
- 触控板手势与惯性滚动保持系统行为，命令键或控制键组合滚动也交由原应用处理。
- 可选择应用或填写应用标识加入排除名单，排除后沿用原生方向、速度和滚动，与剪贴板排除名单分别管理。
- 钉图滚轮缩放和本应用设置页保持原有操作；锁屏和休眠时暂停，恢复后按已保存的开关继续运行。
- 需要辅助功能权限，鼠标页显示运行状态，并提供授权或启动失败后的重试入口。

## 本机与隐私

内容仅保存在本机，无云同步和使用追踪。剪贴板记录、自动粘贴和截图分别使用相应的系统权限。访达自动重命名复用辅助功能权限，新建文件本身无需此权限。截图与录屏仅在主动触发时捕获屏幕，麦克风仅在录屏选项启用且授权后使用。EasyMacOS 仅在用户选择菜单操作时复制路径、创建项目或打开目录，不扫描文件内容。

剪贴板与截图应用的菜单栏菜单、图标提示和设置页均显示当前应用版本。截图与历史快捷键可独立修改，并支持开机启动、在通用设置中切换简体中文或英文，以及系统深浅色外观。通用设置可选择是否在程序坞中显示，默认隐藏，修改立即生效并记住选择；显示后点击图标可打开设置，关闭窗口后继续在后台运行。访达菜单配置与主应用共用界面，同样适配系统深浅色外观。

可从通用设置、菜单栏菜单或应用菜单点击“检查更新”，查看新版本说明并确认下载安装，完成后重新启动应用。仅在主动检查时连接更新服务，不后台检查或静默安装。

## 语言与技术栈

项目采用原生 macOS 技术栈，最低支持 macOS 15.0，当前面向 Apple Silicon（`arm64`）。

| 类别 | 技术 | 版本说明 | 用途 |
| --- | --- | --- | --- |
| 编程语言 | `Swift` | 6，当前本机编译器为 6.4 | 应用、访达扩展及核心逻辑 |
| 界面框架 | `SwiftUI`、`AppKit` | 随系统提供 | 设置与历史界面、菜单栏、截图浮层与桌面钉图 |
| 状态管理 | `Observation` | 随系统提供 | 设置、应用状态与界面同步 |
| 屏幕与音视频 | `ScreenCaptureKit`、`AVFoundation` | 随系统提供 | 截图、屏幕录制、声音采集与视频导出 |
| 访达扩展 | `FinderSync` | 随系统提供 | 访达右键菜单与文件操作入口 |
| 系统集成 | `CoreGraphics`、`ApplicationServices`、`Carbon`、`ServiceManagement` | 随系统提供 | 鼠标事件、辅助功能、全局快捷键与开机启动 |
| 本地存储 | `SQLite` | 系统提供的 3 系列，具体版本随系统变化 | 保存剪贴板历史与收藏 |
| 应用更新 | `Sparkle` | 固定为 2.10.1 | 用户主动检查更新、下载安装 |
| 包管理 | `Swift Package Manager` | 包清单要求工具版本至少为 6.0 | 管理模块、依赖与构建 |
| 测试框架 | `Swift Testing` | 随第六代及后续语言工具链提供 | 核心逻辑与功能测试 |

系统框架通过 macOS 开发工具包编译、由运行系统提供，不单独锁定版本。第三方依赖版本以 [`Package.swift`](Package.swift) 与 [`Package.resolved`](Package.resolved) 为准。
